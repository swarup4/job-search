Guardrails — where each one is enforced

The seven invariants from CLAUDE.md, checked against the code as it stands.

InvariantStatusEnforced by
1 · No fabricationHeldThe selection Set starts empty (keywords/page.jsx). The server accepts only keys ⊆ missing. storeResume needs the gate selected and incorporated ⊆ selected. Tailoring's review() rejects invented words. Every agent verifies model output against the source text. Tests: test_no_fabrication.py, and the compromised-model cases in test_guardrails.py.
2 · No auto-submitHeldscan.ts skips submit and button controls. No submit(), requestSubmit or synthetic Enter appears anywhere (test-enforced). Marking a job applied requires confirmedByUser, or the server returns 409.
3 · Generation is localHeldAll generation goes through config/llm.py to Ollama/vLLM. voyageai is imported only in rag/embeddings.py and rag/retrieval.py. Tests ban hosted LLM URLs, hosted SDKs and :cloud models.
4 · Split storeChangedOne Atlas store, owned by the server. The ai tier has no database at all. The boundary is enforced by HTTP plus the forwarded JWT, not by two connection strings.
5 · .tex onlyPartlyThe tailoring output is .tex. The server compiles a PDF on demand for download, a deliberate reversal noted in compile.py.
6 · Localhost onlyHeldBoth servers default to 127.0.0.1. CORS allows only :3000 and chrome-extension://. A test fails on 0.0.0.0 or a wildcard origin.
7 · Steps pauseHeld, differentlyThe keyword gate is server state (review.state), not a LangGraph interrupt. Submitting is human-only, recorded through confirmedByUser.
